# PC-Workshop
PC Workshop is a web development project created during my studies. The website focuses on PC building and hardware, allowing users to create accounts, log in, and make posts about their builds, components, upgrades, and other PC-related topics.


Requirements to Run

XAMPP with Apache and MySQL/MariaDB
PHP installed through XAMPP
MySQL database configured for the website
Website files placed in the XAMPP htdocs folder
Internet connection for any external resources such as Bootstrap or fonts.
